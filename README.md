# CritiqueCore

Веб-платформа для обговорення навчального коду, лабораторних робіт і Code Review.
Автор навчального проєкту: Дмитро Бабічук, УжНУ, Інженерія програмного забезпечення.

## Поточний етап

Лабораторна робота 2: дизайн. Підготовлено чотири основні сторінки,
вхід, реєстрацію та UI Kit із компонентами і станами.
Майбутня реалізація платформи — React із Vite; бекенд запланований на Node.js/Express.
Приклади Next.js та інших технологій у дописах — демонстраційний контент спільноти.

## Сценарій прототипу

Вхід → стрічка → створення теми / обговорення / Code Review.
Екрани входу та реєстрації пов’язані між собою.
Переходи демонструють сценарій; авторизація, дані та серверна логіка поки не реалізовані.

## Наступні етапи

Каркас React/Vite, структура компонентів, адаптивна верстка,
клавіатурна навігація, валідація форм і взаємодія з сервером.
