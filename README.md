# CritiqueCore

## Лабораторна робота 5 — маршрутизація

До сторінок ЛР4 підключено React Router у декларативному режимі.
BrowserRouter — у main.jsx; Routes і Route — в App.jsx.
Link виконує переходи, NavLink позначає активний пункт меню.

## Запуск

Потрібні Node.js 22.22+ і Git.

```sh
npm ci
npm run dev
```

Адреса: http://localhost:5175/

## Маршрути

- / — стрічка обговорень.
- /create — створення теми.
- /discussion — приклад обговорення.
- /review — Code Review.
- /login — вхід.
- /register — реєстрація.
- Інша адреса — сторінка «Сторінку не знайдено».

Зі стрічки можна перейти до створення теми, обговорення, Code Review та входу.
Форми входу й реєстрації пов’язані посиланнями; логотип повертає до стрічки.
Кнопки публікації та входу залишаються статичними: бізнес-логіка й API належать до наступних робіт.

## Команди

- npm run lint — ESLint.
- npm run format:check — перевірка форматування.
- npm run build — збірка.
- npm run check — усі три попередні команди.

Початкові Cypress перевірки та Git hooks збережено з попередніх етапів.
Для майбутнього хостингу BrowserRouter потребує повернення index.html для невідомих серверу шляхів.
